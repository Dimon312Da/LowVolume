# LowVolume

Android-приложение, которое не даёт поднять громкость телефона выше заданного лимита.
Поднять лимит, убрать поток из-под ограничения или выключить защиту можно только
после ввода пароля в приложении.

## Как это работает

- При первом запуске нужно придумать пароль (минимум 4 символа). После этого
  ограничение включается сразу (по умолчанию — 50 % для музыки/видео/игр).
- В фоне работает сервис с постоянным уведомлением. Как только громкость становится
  выше лимита (кнопками, из шторки, из другого приложения, при подключении наушников
  или Bluetooth), он сразу понижает её обратно.
- Без пароля лимит можно только **уменьшать** и добавлять потоки под ограничение.
- После ввода пароля настройки разблокируются до выхода с экрана приложения: можно
  поднять лимит, убрать потоки, выключить защиту, сменить пароль.
- После 5 неверных попыток ввод пароля блокируется на 30 секунд, дальше время
  блокировки удваивается (до 1 часа).
- Защита автоматически запускается после перезагрузки телефона.

Можно ограничивать: музыку/видео/игры, звонок, уведомления, будильник, разговор.

### Дополнительно

- **Защита от удаления** — приложение становится администратором устройства, и его
  нельзя удалить, пока эта защита не отключена. Отключение в приложении требует пароль.
- **Работа в фоне** — кнопка отключает оптимизацию батареи для приложения, чтобы
  система (особенно на Xiaomi, Huawei, Samsung и т. п.) не останавливала сервис.
  На некоторых прошивках дополнительно нужно разрешить «Автозапуск».

## Ограничения

Обычное приложение не может полностью заблокировать телефон, поэтому:

- защиту можно обойти через «Настройки → Приложения → LowVolume → Остановить»
  или удаление (если не включена защита от удаления — тогда сначала нужно отключить
  администратора в настройках телефона);
- если забыть пароль, снять ограничение можно только удалив приложение
  или очистив его данные.

Для надёжного ограничения ребёнку стоит дополнительно закрыть доступ к настройкам
телефона (например, через Google Family Link).

## Сборка

Нужны JDK 17+ и Android SDK (platform 35).

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Готовый APK также собирается в GitHub Actions при каждом пуше
(вкладка **Actions → Build APK → Artifacts**).

Минимальная версия Android — 8.0 (API 26).
